  1. 1

    准备独立环境

    安装本工具；RVC、分离后端、讲话服务按需分别配置，不把所有依赖塞在一起。

  2. 2

    填好本地配置

    从示例复制一份 config.local.json，填写自己的模型和路径；这份配置不公开。

  3. 3

    诊断，再做短样

    先检查缺失项和测试，再用明确授权的素材验证，最后决定是否处理整曲。

BEFORE YOU RUN

值得先知道的事。

项目里有现成音色和歌曲吗？

没有。只提供通用代码、文档、示例和合成测试。请自行准备有授权的素材、模型与参考录音。

能一键帮我把全部依赖装好吗？

AI 接手说明可以帮助配置，但仍受宿主权限和授权范围约束。上游版本、模型与环境需要核对，下载和训练不会自动开始。

说话的模型可以直接拿来唱歌吗？

本工具的讲话路线使用 GPT-SoVITS，翻唱路线使用 RVC，两类权重不能互换。RVC 也不是从歌词自动作曲。

精唱是不是保证没有电音和双主唱？

不能保证。输入、训练覆盖和分离误差都会影响效果。项目保留来源和参数记录，要求检查角色与交叠处，听审仍由使用者完成。

现在验证到了哪一层？

源码预览包含计划、替身编排、合成音频与模拟讲话接口测试。完整真实后端需在你的环境用授权短样验收；不冒充所有设备都已跑通。
