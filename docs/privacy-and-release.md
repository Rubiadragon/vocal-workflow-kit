# 隐私与发布

## 包里可以有什么

原创通用代码、说明、示例配置、合成数据生成测试、静态主页、上游链接和许可证。

## 包里不能有什么

真实音色权重、检索索引、G/D断点、歌曲、语料、参考录音、参考文本、本地配置、环境变量、账号标识、令牌、Cookie、聊天记录、人设、记忆、日志、运行租约、真实路径、模型缓存、可执行整合包。

默认不从任何私人工作目录复制整棵树。发布脚本只读取本项目的明确白名单，遇到敏感模式、链接、二进制或未允许后缀会失败。
它不能证明每种未知隐私都已识别，因此还需人工核对发布清单。

## 发布步骤

1. 只保留本仓库通用内容；本地配置与数据放忽略目录。
2. 跑测试，记录passed/skip与真实推理是否验证。
3. `python scripts/release.py --check`。
4. `python scripts/release.py --output ../vocal-workflow-kit-public.zip`。
5. 解包核对清单、SHA256和实际文件；确认没有.git历史或嵌套压缩包。
6. 再由维护者决定发布平台、作者名、仓库URL和版本说明。本脚本不会上传。

项目主页位于docs/index.html，全部资源本地化、无统计追踪和外部字体。可本地预览；准备发布GitHub Pages时选择docs目录。
不附带默认部署工作流，避免把一个“想开源”的请求变成自动公开上传。
