# 快速翻唱：先听方向，再决定是否精做

[文档导航](INDEX.md) / 快速翻唱

本公开实现使用单阶段MSST分离＋普通RVC调用＋混音。它不包含任何人的QQ桥接代码，也不声称与某个私有 `qq_sing` 逐样本相同。

```powershell
python -m vocal_workflows quick --source "input/song.wav" --dry-run
python -m vocal_workflows quick --source "input/song.wav"
```

## 和精唱的区别

| 项目 | quick | fine |
|---|---|---|
| 分离阶段 | 1：全人声／乐器 | 2：再拆候选主唱／背景 |
| overlap / batch | 2 / 1 | 8 / 1 |
| TTA | 关闭 | 开启 |
| 换声对象 | 分离出的全人声 | 已确认的指定主唱 |
| 音高 | 常规上游调用 | 16k／100Hz轨保存与冻结 |
| 适合 | 快速试音色与选歌 | 注重主唱与编排的完整制作 |

快不等于一定几秒出片；时长、GPU、模型和其他任务都会影响耗时。
多人对唱、口号和复杂和声可能一起被转换；想保留这些原声，应使用精唱并先核对角色。

## 调参要有对照

复制一份本地配置，固定输入和片段，先比较index=0与0.3，再单独比较移调。
不要为了更“像”而同时改变index、protect、音高和后期，再无法判断改善来自哪里。
原唱唱法不适合目标声线时，换一份干净、表达合适的输入通常比堆后期更值得试。

所有数字都是可改的示例，不自动适配男女声。公开包不包含B站登录、下载器、平台发送、付费云端生成或后台关闭工具。
