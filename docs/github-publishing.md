# 上传 GitHub 与启用主页

这是源码仓库，README 是 GitHub 仓库首页，静态网页由 GitHub Pages 单独展示。

## 上传前

1. 运行 `python scripts/release.py --check`，审阅发布清单。
2. 使用发布脚本生成的 ZIP；解压后上传里面的源码文件。不要只把整个 ZIP 当作仓库唯一文件。
3. 不要从自己的运行目录直接全选上传。模型、音源、参考录音、配置、日志和聊天记忆不属于公开仓库。

## 仓库与主页

在自己的 GitHub 账号建立仓库，上传审核后的文件，保持目录结构。首次提交的分支通常为 `main`，以自己的仓库为准。

如需启用网页，在仓库 Settings → Pages 选择 **Deploy from a branch**，选择已上传的分支与 **/(root)**。请使用根目录，不能选 `/docs`：主页里的 AI 接手说明、许可证等链接需要访问仓库根文件。

根目录 `index.html` 会跳转到 `docs/index.html`。`.nojekyll` 保留静态文件结构。Pages 显示发布成功后，将它提供的真实网页链接添加到仓库 About 的 Website，并更新 README 的主页入口。不要猜测用户名或站点地址。

上传源码与开启 Pages 都是对外发布步骤，应由仓库拥有者决定。本工具不会自动上传。

## 让群友交给 AI

将真实仓库链接与 `AI_HANDOFF.md` 中的提示词发给群友。AI 先读取 `AGENTS.md`、适用技能、兼容说明，再诊断环境、配置路径、运行测试和短样验收。模型及授权素材由使用者自己准备。

## 反馈问题

使用仓库的 Bug 模板；可附工具生成的脱敏诊断包。不要公开原始日志、私人音频、本地完整配置或密钥。16 项本地验证覆盖流程层与合成音频，不代表任意上游版本或真实音色已经通过验收。
