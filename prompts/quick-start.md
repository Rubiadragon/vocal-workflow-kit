# 通用任务提示词

## 配置与排错

请先读 AGENTS.md 和 AI_HANDOFF.md。确认我想做讲话、音色训练、精唱还是快唱，先运行测试与doctor，列出依赖缺失。获得相应授权后再配置本地环境。不要上传文件、自动训练、关后台或绕过权限。修bug前备份，不改音色或音调来掩盖问题，保留已有产物，并区分计划、替身测试与真实推理。

## 精唱

使用我本次提供且有授权的音源与RVC音色。先核对主唱角色，不按男女或是否说唱分类。只转换指定主唱，其他背景人声与乐器默认保留。两阶段分离后检查交叠处与双主唱；不确定先给代表性短样。同源合格分离复用，不重跑；固定本次参数，整曲单独保存，报告来源、时长、峰值、背景混音和试听状态。不要对外发送。

## 快速翻唱

用quick入口对我指定音源做试听，先确认模型和参数。说明单阶段会把分离出的全人声一起转换，复杂客串和和声需要精唱再处理。不要把快速结果冒充已完成角色核对的精唱，也不要自动换音调。

## 讲话

使用我配置的本地GPT-SoVITS API v2和授权参考录音。先核对服务与语言，不切换正在使用的模型，不上传参考音频。用我指定文字生成WAV，检查文件后供我试听。不要把TTS念歌词当作唱歌，也不要使用RVC权重代替讲话模型。

## 训练准备

先区分训练讲话音色还是唱歌换声音色。检查授权语料、干净程度、音域／音素覆盖与留出测试，运行dataset-audit。准备匹配版本的预处理、F0与特征步骤，生成计划并解释资源需求；本次先不启动训练。不要公开我的数据、文件名、参考文本、权重、索引或断点。
